# Projektregeln

## Commits und Pull Requests

Commit-Nachrichten und PR-Beschreibungen enthalten ausschließlich die Beschreibung der
Änderung. Keine Werkzeug- oder Assistenz-Signaturen, keine Co-Autoren-Zeilen, keine
Session-Links, keine Footer.

Der Hinweis auf KI-Unterstützung steht an genau einer Stelle: unten in der `README.md`.
